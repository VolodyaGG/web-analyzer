# DevOps Pet-Project: Web-pinger & Auditor

Репозиторий для пошаговой реализации локальной платформы низкоуровневого сетевого анализа и мониторинга веб-сервисов с упором на хардкорный Linux, сети и DevSecOps.

- [ ] Спринт 1: Фундамент и IaC (День 1-3)
- [ ] Спринт 2: Сетевой хардкор на уровне ядра (День 4-6)

- [ ] Спринт 4: Проксирование, Автономность и Мониторинг (День 9-12)

## Спринт 2: Сетевой хардкор (Linux Network Stack)

### [ ] День 4: Сетевая изоляция через Network Namespaces
* **Задача:** Вручную изолировать сетевой стек, создать виртуальный сетевой кабель и настроить NAT в интернет.
* **Ключевые концепции:** Linux Network Namespaces (`netns`), `veth`-пары, Маршрутизация, `iptables`, NAT.
* **Чек-лист выполнения:**
  - [ ] Создано пространство имен `ns_worker`.
  - [ ] Создана пара виртуальных интерфейсов `veth_host` и `veth_worker`.
  - [ ] Интерфейс `veth_worker` успешно проброшен внутрь `ns_worker`, обоим концам назначены IP-адреса.
  - [ ] Настроены правила `iptables` (маскарадинг) на хосте виртуалки для выпуска трафика из `netns`.
  - [ ] Команда `sudo ip netns exec ns_worker curl https://google.com` успешно возвращает HTML-код.
